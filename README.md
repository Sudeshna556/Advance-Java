# Advance-Java
This repository contains my practice programs and projects in Advanced Java, focusing on building strong backend development skills. It covers core concepts and enterprise-level features.

# 🔑 Key Topics
JDBC → DriverManager, PreparedStatement, CallableStatement, Transactions, ACID properties

Servlets & JSP → Request/response flow, session management, MVC basics

Spring Boot → Controllers, Services, Repositories, REST APIs, JWT-based security

OOP Fundamentals → Constructors, static vs instance, encapsulation, inheritance

Database Integration → MySQL connectivity, query execution, stored procedures

Authentication & Security → Cookies, JWT, bcrypt hashing

# 🎯 Purpose 
Strengthen backend development skills with Java EE and Spring Boot.

Build reusable code snippets and mini-projects for real-world applications.

# 🚀 How to Run
Clone the repository.

Compile using javac or run via IDE (IntelliJ/Eclipse).

For Spring Boot projects, use:

```bash
mvn spring-boot:run
```
